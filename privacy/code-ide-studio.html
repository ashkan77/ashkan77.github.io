Code IDE Studio Privacy Policy

Last updated: 26 October 2026

Data collection

Code IDE works locally on your Mac. It has no developer-operated account, analytics service, advertising SDK, tracking, or automatic upload of your source code. The developer does not collect data through the app. Apple may process App Store purchases and diagnostics according to your Apple settings and Apple's privacy policy.

Files and local recovery

Files and folders you select are used for editing, searching, saving, and running your code. macOS access bookmarks let the app reopen your selections. Workspace settings, recently opened file paths, editor state, and recovery copies of unsaved changes are stored locally in the app's container. Recovery records are removed as saved or discarded changes are reconciled. Your saved project files remain in the locations you choose.

Environment values

Global Run defaults, Run Target and language environment values are stored in macOS Keychain. Local settings contain references to these values. The values are supplied to a process only when you run your code or explicitly check the configured tool. Keychain entries can remain after uninstalling the app; you can remove CodeIDE.runTarget and CodeIDE.environment entries using Keychain Access. Exporting an environment file is an explicit action that creates a plain-text copy at your chosen location.

Your code and external tools

Code IDE does not install language runtimes or packages. You choose existing tools and when to run them. Your programs and tools may read files or contact services within the permissions available to them. Their behavior and the services they contact are determined by that code, its configuration, and their own privacy policies. Review code before running it. The local Git interface does not push changes to a remote repository.

Devices, camera, and network

Serial and network consoles exchange only the data you choose to send with the device or host and port you select. TLS is optional and is shown in the network console. Received data is displayed locally. Camera access is requested only when you start a preview. Camera frames are neither recorded nor transmitted by Code IDE; the preview stops when you leave its page or switch away from the app. There is no microphone capture or global keyboard monitoring.

Optional system features

Spotlight indexing is off by default. You may enable local indexing of filenames and, separately, source text in Settings. Disabling indexing requests removal of Code IDE's entries from Spotlight. Run-completion notifications are optional and can be disabled in Settings or macOS notification settings.

Export and sharing

Export and Share actions create or send the content you select using the destination you choose. A workspace export can contain source code; review it before sharing. Settings backups omit run arguments and environment values. Nothing is sent to the developer automatically. Information you choose to provide when requesting support is used to respond to that request.

Retention and control

You control your project files, exports, and local preferences. Local recovery and settings remain on your Mac until removed by the app's normal workflow, you, or macOS. You can revoke camera, network, and notification permissions in System Settings. You can disable Spotlight indexing in Code IDE before removing the app. There is no Code IDE account or server-side profile to delete.

Contact

For questions about privacy or deletion, contact azanjani@me.com. Include Code IDE Studio in the subject and do not send private source code, credentials or unnecessary personal information.
