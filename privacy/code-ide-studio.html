Code IDE Studio Privacy Policy

Code IDE Studio is a native code editor that works locally on your Mac. It has no account, no analytics, no tracking, and no automatic upload of your source code. The developer does not collect data through the app.

In development. Code IDE Studio is not yet available on the App Store. This page describes the current build for Apple silicon Macs running macOS 26 or later.

Summary

Code IDE Studio works locally on your Mac. It has no developer-operated account, analytics service, advertising SDK, tracking, or automatic upload of your source code, and the developer does not collect data through the app.

Files and local recovery

Files and folders you select are used for editing, searching, saving, and running your code. macOS security-scoped bookmarks let the app reopen your selections. Workspace settings, recently opened file paths, editor state, and recovery copies of unsaved changes are stored locally in the app's container. Recovery records are removed as saved or discarded changes are reconciled. Your project files remain in the locations you choose.

Environment values

Global Run defaults, Run Target, and language environment values are stored in the macOS Keychain; local settings hold only references to them. Values are passed to a process only when you run your code or explicitly check a configured tool. Keychain entries can remain after you remove the app; delete the CodeIDE.runTarget and CodeIDE.environment entries in Keychain Access if you no longer need them. Exporting an environment file is an explicit action that creates a plain-text copy where you choose.

Your code and external tools

Code IDE Studio does not install language runtimes or packages. You choose existing tools and when to run them. Your programs and tools may read files or contact services within the permissions available to them, and their behavior is governed by that code, its configuration, and the tools' own privacy policies. Review code before running it. The local Git interface never pushes changes to a remote repository.

Devices, camera, and network

Serial and network consoles exchange only the data you choose to send with the device, host, and port you select. TLS is optional and shown in the network console. Received data is displayed locally. Camera access is requested only when you start a preview; frames are neither recorded nor transmitted, and the preview stops when you leave its page or switch apps. There is no microphone capture or global keyboard monitoring.

Optional system features

Spotlight indexing is off by default. You can enable local indexing of file names and, separately, source text in Settings; turning indexing off asks macOS to remove Code IDE Studio's entries. Run-completion notifications are optional and can be turned off in the app or in macOS notification settings.

Export and sharing

Export and Share create or send only the content you select, to the destination you choose. A workspace export can contain source code, so review it before sharing. Settings backups leave out run arguments and environment values. Nothing is sent to the developer automatically.

Diagnostics and analytics

Code IDE Studio contains no third-party analytics, advertising, or tracking SDKs and does not send usage data to a developer-operated server. If you choose to share analytics with app developers in Apple's settings (System Settings > Privacy & Security > Analytics & Improvements), Apple may give the developer crash reports and performance information. Apple also provides aggregated App Store metrics such as downloads and sales. Apple supplies this information in aggregated or de-identified form, and it is used only to fix problems and improve reliability.

Support communication

If you email support, your email address and whatever you choose to include are used only to answer your request. Messages are handled through the developer's Apple iCloud Mail account and kept only as long as needed to resolve the request and keep a reasonable record of it. Please leave out passwords, payment details, and any personal information that is not needed to understand the problem.

Retention and control

You control your project files, exports, and local preferences. Local recovery data and settings remain on your Mac until the app's normal workflow, you, or macOS removes them. You can revoke camera, network, and notification permissions in System Settings and turn off Spotlight indexing before removing the app. There is no Code IDE Studio account or server-side profile to delete. Support emails are deleted on request.

Your privacy rights

Depending on where you live, laws such as the EU and UK General Data Protection Regulation (GDPR), Türkiye's Personal Data Protection Law No. 6698 (KVKK), and US state privacy laws may give you the right to know what personal data is processed, to access or receive a copy of it, to correct or delete it, to restrict or object to its processing, and to complain to a data-protection authority.

Code IDE Studio does not send your app data to the developer, so most of it stays on your devices under your direct control. For information you have sent by email, write to azanjani@me.com from the same address so the request can be verified. Requests are answered within 30 days. Personal information is never sold or shared for cross-context behavioral advertising.

Security

Code IDE Studio keeps its data in the app's own container, protected by Apple's platform security, including the macOS app sandbox and FileVault disk encryption when it is turned on. Keep your device updated and protected with a passcode. No storage method is perfectly secure, so only keep information you are comfortable storing on your device.

Children

Code IDE Studio is a developer tool and is not directed to children. It does not knowingly collect personal information from anyone.

Changes to this policy

This policy is reviewed whenever Code IDE Studio adds a feature that affects personal data, Apple platform behavior changes, or the App Store privacy disclosure changes. The date at the top shows the latest revision. Material changes are published here before the app version that introduces them.

Contact

The developer and data controller for Code IDE Studio is Ashkan Zanjani. For privacy questions or requests, email azanjani@me.com. For troubleshooting, visit Code IDE Studio Support. Apple's own processing is described in the Apple Privacy Policy.
