Code IDE Studio Support

Code IDE Studio is in development for Apple silicon Macs running macOS 26 or later. This page describes the current product and its acceptance limits; it is not an announcement of App Store availability.

Contact support

Email azanjani@me.com with Code IDE Studio in the subject. Support is available in English and Turkish. Include the app version, macOS version, language/tool version, the exact steps, expected result and a redacted error message. Do not send private projects, credentials or environment secrets.

Files and recovery

Open File edits the original. Import makes a workspace copy. If a save fails, keep the document open and inspect its error; Save As can preserve a separate copy. Compare external changes before replacing either version. Interrupted Replace All operations offer before, planned, buffer and disk review plus snapshot-copy recovery. Local recovery is not a backup.

Running programs

Code IDE does not bundle or install language runtimes or packages. Choose an existing toolchain and review its access in Settings. Run File uses the selected file; Run Target uses a supported project route. Native compiled-program execution in the signed sandbox is still under acceptance testing and is not claimed as universally available. Local web/development servers and programs opening network listeners are outside the current signed product scope, including server-based npm start targets.

Console

Edit input in the field below the output, then choose Send or press Return. EOF closes standard input; Interrupt sends SIGINT; Stop terminates the owned process group. Rejected input remains in the field. This Console is a program stream, not a full terminal emulator.

Git and permissions

Enable Git only for a folder you trust: repository configuration can invoke filters and hooks. Git can be disabled again in Source Control. The app does not push commits. Select files, folders and tools through the normal macOS access panels. Do not disable system security protections to work around a failed run.

Devices

The TCP/TLS console connects to an existing host and port; it does not host a service. Serial access depends on the device and driver. Camera preview starts only after an explicit action and permission and does not record or transmit frames. Firmware flashing and driver installation are not included.

Privacy

The Code IDE Studio privacy policy describes local files and recovery, Keychain environment values, optional Spotlight indexing, exports, external tools and support communication. No developer-operated analytics or automatic source-code upload is included.
