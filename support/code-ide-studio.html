Running programs

Choose File > New File, pick a language and press Command-R. Python, Node.js, TypeScript, Java, Kotlin, C#, Ruby, PHP, Perl, Bash, Lua, R, Julia and Dart run with included macOS runtimes. C, C++, Go, Rust and Swift compile to WebAssembly and run in the included WASI Console, which is single-threaded and has no host files outside the workspace, network or Apple frameworks. Haskell runs with the included MicroHs. Running code needs no download.

The Native macOS option in Run Configuration is for people with their own macOS toolchain. App Sandbox can prevent programs it compiles from starting; the Console explains this and points to the included console. Local web servers and other programs that open a network listener are not supported.

Debugging and Check

Product > Debug works for single Python, Node.js, TypeScript, Ruby, Lua, Perl, Bash and R files: breakpoints with conditions, stepping, the call stack, variables and expressions. Product > Check (Command-B) finds syntax and compile errors in single files in all 20 languages without running the program, except that Perl runs BEGIN blocks and use statements while checking. Kotlin scripts and project targets don't offer Check.

Tests

Product > Test (Command-U) runs the workspace's tests with the included tools: unittest cases and test_* functions in Python, node --test for JavaScript, and Go and Rust tests built for WebAssembly, where each Rust test runs on its own. The Console's Tests tab lists the results, failures first; choose a failed test's location to open its line. Projects with their own test command (npm test, cargo test, or a go.mod that requires other modules) use it instead, with tools you provide. TypeScript tests need a test script in package.json.

Packages

Product > Packages… adds, updates and removes libraries for Python (PyPI), JavaScript and TypeScript (npm), Ruby (RubyGems), Java and Kotlin (Maven Central), R (CRAN), Dart (pub.dev), PHP (Packagist), Perl (CPAN), Lua (LuaRocks) and Julia (General registry). Julia records dependencies in the project and stores its package files in the app container. The other registries install package files into the workspace.

Packages supports a subset of each registry. npm disables install scripts, RubyGems checks for native extensions and plugins before unpacking, and Julia skips build steps and artifact downloads. Lua evaluates each rockspec with an empty global environment and string methods disabled. Maven libraries are installed only together with their published source JARs. Python updates restore the previous version if they are interrupted. Projects managed by Composer, with composer.lock, are left unchanged. C, C++, Swift, Go, Rust, Haskell, C# and Bash have no package registry in Code IDE Studio.

Files and recovery

Open File edits the original; Import makes a workspace copy. If a save fails, keep the document open and read its error; Save As can keep a separate copy. Compare external changes before replacing either version. Interrupted Replace All operations offer a review and snapshot-copy recovery. Local recovery is not a backup.

Console

Type input in the field below the output, then press Return. End of Input closes standard input, Interrupt sends Control-C and Stop ends the program. Quitting Code IDE Studio ends any program or package operation it started. The Console is a program stream, not a terminal; for a shell with your own tools, choose File > Open in Terminal.

Git and permissions

Enable Git only for a folder you trust: repository configuration can run filters and hooks. Git can be turned off again in Source Control. Fetch, Pull and Push use the repository's HTTPS remote, and File > Clone Repository… clones one; for a private repository, add your user name and a personal access token for the host, which Code IDE Studio keeps in your Keychain. SSH remotes need keys an App Store app can't read. Select files, folders and tools through the standard macOS panels, and never turn off system security protections to work around a failed run.

Devices

The TCP/TLS console connects to an existing host and port and does not host a service. Serial access depends on the device and its driver. Camera preview starts only after you choose it and grant permission, and it doesn't record or send frames. Firmware flashing and driver installation are not included.

Privacy

Code IDE Studio has no analytics, advertising, tracking or account, and never uploads your source code automatically. The network is used only for package operations and Git commands you start, and by programs you run. Read the Code IDE Studio Privacy Policy for the hosts involved and the data each receives.

What to include

Include the app build, macOS version, language and tool versions, the exact steps, the expected result, and a redacted error message. Do not send private projects, credentials, or environment secrets. Remove personal details from screenshots before sending them.
