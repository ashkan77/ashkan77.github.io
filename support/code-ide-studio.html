Files and recovery

Open File edits the original; Import makes a workspace copy. If a save fails, keep the document open and read its error; Save As can preserve a separate copy. Compare external changes before replacing either version. Interrupted Replace All operations offer before, planned, buffer, and disk review plus snapshot-copy recovery. Local recovery is not a backup.

Running programs

Code IDE Studio does not bundle or install language runtimes or packages. Choose an existing toolchain and review its access in Settings. Run File uses the selected file; Run Target uses a supported project route. Native compiled-program execution in the signed sandbox is still under acceptance testing and is not claimed as universally available. Local web or development servers and programs that open network listeners, including server-based npm start targets, are outside the current signed product scope.

Console

Type input in the field below the output, then choose Send or press Return. EOF closes standard input, Interrupt sends SIGINT, and Stop ends the owned process group. Rejected input stays in the field. The Console is a program stream, not a full terminal emulator.

Git and permissions

Enable Git only for folders you trust, because repository configuration can run filters and hooks. You can turn Git off again in Source Control. The app does not push commits. Select files, folders, and tools through the standard macOS access panels, and never disable system security protections to work around a failed run.

Devices

The TCP/TLS console connects to an existing host and port and does not host a service. Serial access depends on the device and its driver. Camera preview starts only after an explicit action and permission and does not record or transmit frames. Firmware flashing and driver installation are not included.

Privacy

Code IDE Studio has no developer-operated analytics and never uploads your source code automatically. Read the Code IDE Studio Privacy Policy for details.

What to include

Include the app build, macOS version, language and tool versions, the exact steps, the expected result, and a redacted error message. Do not send private projects, credentials, or environment secrets. Remove personal details from screenshots before sending them.
