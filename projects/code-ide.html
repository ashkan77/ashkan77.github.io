Code IDE Studio

A native Mac code editor built around a calm workspace: project navigation, editing, search and replace with recovery, a program console, Git, and device consoles — local-first, with no account and no automatic source-code upload.

Product direction

Code IDE Studio is a focused, Apple-native editor rather than a cross-platform shell. The interface favors an editor-first layout, a refined toolbar, clear project navigation, and system conventions for files, permissions, and windows.

It works with the toolchains already installed on the Mac instead of bundling its own, and runs inside the macOS sandbox with explicit access to the files, folders, and tools the user selects.

Core experience

  • Open files in place or import them into a workspace copy
  • Project-wide search and Replace All with review and snapshot recovery
  • Run File and Run Target with an interactive program console
  • Optional Git integration for trusted folders
  • Serial and TCP/TLS device consoles
  • Optional local Spotlight indexing, off by default

Privacy and safety

Code stays on the Mac. Environment values are stored in the macOS Keychain, Git never pushes on its own, and there is no developer-operated analytics. The support page also documents current limits, such as local servers being outside the signed product scope.
